# 🥦 FarmMarket Homepage

A responsive React + Tailwind CSS homepage for a local farm marketplace. Users can browse fresh products, view farmers, and add new items.

## 🔧 Tech Stack
- React.js (with Vite)
- Tailwind CSS


## 📂 Features
- 🧭 Responsive Header with navigation
- 🖼️ Hero section with background image
- 🛒 Product cards dynamically rendered
- ➕ Add Product form as modal
- 📦 Products persisted even after refresh

## 🚀 Getting Started

```bash
npm install
npm run dev
